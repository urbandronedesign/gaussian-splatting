4 · Contexte 20264 · Context in 2026

  • glTF. L'extension KHR_gaussian_splatting, annoncée en février 2026, est marquée « ratifiée » dans le registre Khronos depuis septembre 2026 : les splats entrent dans le standard 3D du web.
  • Apple. RealityKit affiche des splats nativement (WWDC 2026, démonstration sur Vision Pro).
  • Web. Visionneuses libres : PlayCanvas / SuperSplat, Spark (three.js).
  • Recherche. Le code de référence de 2023 (graphdeco-inria) reste sous licence de recherche non commerciale ; les outils du cours sont des réimplémentations libres.
  • glTF. The KHR_gaussian_splatting extension, announced in February 2026, has been marked "ratified" in the Khronos registry since September 2026: splats are entering the web's 3D standard.
  • Apple. RealityKit displays splats natively (WWDC 2026, demonstrated on Vision Pro).
  • Web. Open viewers: PlayCanvas / SuperSplat, Spark (three.js).
  • Research. The 2023 reference code (graphdeco-inria) remains under a non-commercial research licence; the course tools are open reimplementations.
